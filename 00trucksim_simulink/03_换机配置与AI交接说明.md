# 阶段一换机配置与AI执行说明

## 给新电脑AI的任务

本文件只对应`00trucksim_simulink`。该文件夹可单独复制到新电脑并独立运行，不依赖其他项目文件夹。

阶段一使用TXT用例生成第一轴开环转向，Simulink通过TruckSimS-Function运行车辆动力学，MATLAB导出CSV；本地Python模块负责TruckSim工况配置、PNG和Word报告。第二、第三轴转角固定为0度。

## AI的询问规则

AI先做不写入的文件和路径检查，不要逐项要求使用者填写路径。确认需要修改的项目配置后，只询问一次：

```text
已定位目标机环境和需要修改的项目配置。是否允许我修改run_case_new.m、安装缺少的Python依赖，并执行只读检查？
```

这次确认不包含真实仿真。真实仿真可能修改TruckSim当前Run关联的`.par`文件，只有使用者之后明确要求运行时才可执行。

AI不得删除或批量改写`03_数据存储`、`04_测试报告`中的历史结果；不得覆盖`.slx`模型；不得修改历史CSV、Word报告、PNG或日志。

## 使用者必须先完成的TruckSim操作

1. 在目标电脑安装MATLAB、TruckSim和Python。
2. 在TruckSim中导入本目录的`ORAC-BLFISMC1017 #phase1.cpar`。
3. 选中阶段一要使用的Run，并执行“发送到Simulink”。
4. 在MATLAB的`01_一键启动脚本`目录运行`capture_phase1_simfile`。脚本会在TruckSim数据目录生成`simfile_phase1.sim`，并在项目内保存路径记录`runtime/trucksim_phase1.path`。

若Run未选定、未发送到Simulink或未执行保存脚本，AI应提示使用者先完成上述操作；不得猜测Run名称或任选同名`simfile.sim`。若同级阶段二入口在新电脑有效，保存脚本会拒绝与其指向同一`Run_all.par`；若阶段二路径仍是旧电脑无效路径，只会警告并要求后续重新配置阶段二。

## AI自动检查步骤

### 1. 确认阶段一文件完整

将本文件所在目录视为阶段一根目录，确认以下关键文件存在：

```text
00_simulink/new_three_axle_vehicle_2dof_3dof_Trucksim.slx
00_simulink/three_parameter1.m
01_一键启动脚本/run_case_new.m
01_一键启动脚本/parse_case.m
01_一键启动脚本/export_case_csv.m
01_一键启动脚本/trucksim_config.m
01_一键启动脚本/configure_trucksim_case.py
01_一键启动脚本/trucksim_config_backend.py
01_一键启动脚本/capture_phase1_simfile.m
runtime/trucksim_phase1.path
01_一键启动脚本/make_test_report_new.py
02_测试用例/
ORAC-BLFISMC1017 #phase1.cpar
requirements.txt
```

`trucksim_config_backend.py`是阶段一自己的TruckSimCOM和`.par`回退模块。找不到它时，阶段一不能进行严格工况配置，AI应停止并报告，不得改为依赖其他项目文件夹。

### 2. 定位目标机外部环境

1. 查找可用的`python.exe`并读取版本。
2. 确认Python可导入`numpy`、`matplotlib`和`docx`；缺少时待获得确认后安装。
3. 查找TruckSimsolver目录，确认其中有`Matlab84+`子目录。
4. 查找使用者刚在TruckSim中“发送到Simulink”后生成的源`simfile.sim`，读取其`INPUT`配置并确认能定位到当前Run关联的`.par`参数文件。
5. 确认项目内`runtime/trucksim_phase1.path`存在，且其中记录的`simfile_phase1.sim`的`INPUT`与第4步的阶段一Run一致；不得直接把共享源文件设为运行入口。

### 3. 获得确认后修改项目配置

AI只允许修改`01_一键启动脚本/run_case_new.m`中的以下变量：

| 变量 | 应填写的内容 |
|---|---|
| `pythonExe` | 目标机实际`python.exe`完整路径 |
| `trucksimSolverDir` | 目标机TruckSimsolver目录 |

`trucksimSimFile`会从项目内`runtime/trucksim_phase1.path`读取TruckSim数据目录中的`simfile_phase1.sim`，不得改回共享源文件`simfile.sim`。`mdlPath`、`caseFile`、`dataRoot`和报告脚本根目录都已按脚本位置自动定位，不得写入新电脑桌面路径。只有使用者指定其他工况时，才修改`caseFile`对应的TXT文件名。

不要修改`.slx`中的模型结构或连线。`run_case_new.m`运行时会将`trucksimSimFile`写入模型`TruckSimS-Function2`的`SIMFILE`参数。

## 依赖检查与只读验证

AI获得确认后，在`01_一键启动脚本`目录使用目标Python执行：

```powershell
& "<python.exe完整路径>" -c "import numpy,matplotlib,docx;print('python deps ok')"
```

缺少依赖时执行：

```powershell
& "<python.exe完整路径>" -m pip install -r "<阶段一项目根目录>\requirements.txt"
```

若要尝试TruckSimCOM自动配置，可安装：

```powershell
& "<python.exe完整路径>" -m pip install pywin32
```

未安装或无法使用`pywin32`不代表阶段一不能运行；本地配置模块会尝试根据`trucksim_phase1.path`记录的专用simfile的`INPUT`项回退修改关联`.par`文件。

## 真实仿真仅在使用者另行要求后执行

执行`run_case_new`前，AI必须说明：正式仿真会按TXT尝试配置停止时间、初始/目标速度和附着系数；COM不可用时会更新`trucksim_phase1.path`记录的专用simfile所关联的`.par`文件，并在首次修改前创建`.phase1_backup`备份。`road_friction`只通过`MY_FRICTION=目标值/road_base_mu`写入，基准`MU_ROAD_CONSTANT`不会被改写。

使用者确认目标Run和关联数据已备份且允许写入后，AI才可：

1. 在MATLAB中打开模型，但不要直接点击模型运行按钮。
2. 将当前目录切到`01_一键启动脚本`，运行`run_case_new`。
3. 检查`03_数据存储`新增运行目录中的`*_trucksim_io.csv`和`*_case_info.csv`。
4. 检查`04_测试报告`新增目录中的PNG、Word报告和`report_manifest.json`。
5. 确认CSV首行速度、结束时间和第一轴转向与TXT工况一致；不一致时保留结果和日志，不修改CSV伪造通过。

## AI完成配置后的交付内容

AI应汇报已定位的Python、solver、`Matlab84+`、阶段一源simfile和项目内`trucksim_phase1.sim`路径，列出修改过的变量与文件，报告依赖检查结果，并说明尚未运行真实仿真或其可能修改TruckSim`.par`数据的影响。

如果无法确认Run、`simfile.sim`或写入许可，AI只能完成只读检查并报告，不得依赖其他目录、不得猜测路径、不得启动真实联仿。
